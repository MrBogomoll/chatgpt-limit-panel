# Обновление ChatGPT Limit Panel / Updating ChatGPT Limit Panel

## Русский

Скачай готовый ZIP для Windows из [актуального стабильного выпуска](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/latest). Используй архив программы из **Assets**. Кнопка проверки обновлений открывает страницу выпуска; пакет заменяется вручную.

1. Останови панель через её меню или карточку управления.
2. В меню плагинов замени старый пакет ChatGPT Limit Panel скачанным ZIP: удали старый пакет и выбери «Добавить → Загрузить архив плагина».
3. Открой новый чат, выбери **@ → ChatGPT Limit Panel** и отправь **«Открой управление панелью лимитов Codex/Work»**. В появившейся карточке нажми **«Запустить»**.

Новая версия автоматически проверяет и переносит свою остановленную задачу запуска на новый путь. Открывать Планировщик при обычном обновлении не требуется. Выбор автозапуска сохраняется; вручную отключённая задача не включается автоматически.

Не удаляй папку настроек программы: язык, тема, вид, положение, индикаторы и прозрачность сохраняются отдельно от пакета. Если используешь новый помощник удаления, оставь галочку **«Также удалить настройки, положения и журналы»** снятой. При удалении помощником задача запуска создастся заново при следующем запуске.

Если новая версия не запускается, убедись, что старая панель остановлена. При повторной ошибке обратись в [Issues](https://github.com/MrBogomoll/chatgpt-limit-panel/issues). Если задача не проходит проверку владельца и структуры, программа оставляет её без изменений; не удаляй неизвестные задачи вручную.

Для первой установки используй [README](README.md).

## English

Download the built Windows ZIP from the [latest stable release](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/latest). Choose the application archive under **Assets**. Check for updates opens the release page; package replacement is manual.

1. Stop the panel through its menu or control card.
2. Replace the old ChatGPT Limit Panel package in plugins: remove it, then import the downloaded ZIP through **Add → Upload plugin archive**.
3. Start a new chat, select **@ → ChatGPT Limit Panel**, and send **"Open the Codex/Work limit panel controls."** Click **Start** in the card that appears.

The new version automatically validates and relocates its stopped launch task to the new installation path. Routine updates do not require opening Task Scheduler. The autostart choice is preserved; a manually disabled task is not automatically enabled.

Keep the application's preferences folder. Language, theme, view, position, indicators and opacity are stored separately from the package. If using the new removal helper, leave **Also delete settings, saved positions and logs** unchecked. The launch task is recreated on the next start after removal through the helper.

If the new version cannot start, check that the previous panel is stopped. If it still fails, contact [Issues](https://github.com/MrBogomoll/chatgpt-limit-panel/issues). Tasks that fail ownership or structure checks are left unchanged; do not manually delete unknown tasks.

For first installation, follow the [README](https://github.com/MrBogomoll/chatgpt-limit-panel/blob/main/README.en.md).
