# Обновление ChatGPT Limit Panel / Updating ChatGPT Limit Panel

## Русский

Скачай готовый ZIP для Windows из [актуального стабильного выпуска](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/latest). Используй архив программы из **Assets**. Кнопка проверки обновлений открывает страницу выпуска; пакет заменяется вручную.

1. Останови панель через её меню или карточку управления.
2. Открой Планировщик заданий Windows и найди задачу запуска своей панели. Проверь владельца и действие: путь должен вести к программе твоего установленного плагина. Удали только эту остановленную задачу — новая установка создаст её заново. Если владелец или путь не совпадает, оставь задачу и обратись в [Issues](https://github.com/MrBogomoll/chatgpt-limit-panel/issues).
3. В меню плагинов удали старый пакет ChatGPT Limit Panel и загрузи скачанный ZIP через «Добавить → Загрузить архив плагина».
4. Открой ChatGPT Limit Panel и нажми «Запустить».

Не удаляй папку настроек программы: язык, тема, вид, положение, индикаторы, прозрачность и выбор автозапуска сохраняются отдельно от пакета.

Для первой установки используй [README](README.md).

## English

Download the built Windows ZIP from the [latest stable release](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/latest). Choose the application archive under **Assets**. Check for updates opens the release page; package replacement is manual.

1. Stop the panel through its menu or control card.
2. Open Windows Task Scheduler and find your panel's launch task. Verify its owner and action: the executable must belong to your installed plugin. Remove only this stopped task; the new installation will recreate it. If the owner or path does not match, leave the task and contact [Issues](https://github.com/MrBogomoll/chatgpt-limit-panel/issues).
3. In plugins, remove the old ChatGPT Limit Panel package and import the downloaded ZIP through **Add → Upload plugin archive**.
4. Open ChatGPT Limit Panel and click **Start**.

Keep the application's preferences folder. Language, theme, view, position, indicators, transparency and autostart choice are stored separately from the package and are preserved.

For first installation, follow the [README](README.en.md).
