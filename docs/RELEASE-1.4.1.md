# ChatGPT Limit Panel 1.4.1

## Русский

- При переключении размера боковая панель сохраняет положение нижнего края, если выбранное место свободно.
- При уменьшении окна панель может автоматически перейти в ультракомпактный вид и вернуться к выбранному размеру при увеличении окна.
- Улучшено отслеживание положения панели при перемещении окна ChatGPT.

В Windows 11 панель может оставаться видимой поверх предварительного просмотра Snap Layouts. Совместимость с Windows 10 пока исследуется.

Для установки скачайте **chatgpt-limit-panel-1.4.1-windows-x64.zip** из Assets. [Инструкция по обновлению](../UPGRADING.md).

## English

- When switching sidebar sizes, the panel retains its bottom edge when the selected position is available.
- When the window shrinks, the sidebar can automatically switch to ultracompact and restore the selected size when the window grows.
- Improved sidebar position tracking while moving the ChatGPT window.

On Windows 11, the sidebar may remain visible above the Snap Layouts preview. Windows 10 compatibility is still under investigation.

Download **chatgpt-limit-panel-1.4.1-windows-x64.zip** under Assets. See the [upgrade guide](../UPGRADING.md).
