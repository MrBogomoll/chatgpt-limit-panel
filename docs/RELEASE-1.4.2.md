# ChatGPT Limit Panel 1.4.2

## Русский

- Убрано мерцание боковой панели при изменении размера окна, включая увеличение и уменьшение высоты за верхнюю или нижнюю границу.
- Панель сохраняет отображение при переходе из развёрнутого окна в обычное.
- Во время предпросмотра Snap Layouts Windows 11 боковая панель временно скрывается и возвращается после выхода из него.

Совместимость с Windows 10 пока не подтверждена и исследуется отдельно.

Скачайте готовый **chatgpt-limit-panel-1.4.2-windows-x64.zip** из Assets. Git и отдельная установка Node.js не нужны. Проверка обновлений открывает страницу выпуска; установка выполняется вручную. [Инструкция по обновлению](../UPGRADING.md).

## English

- Remove sidebar flicker while resizing the window, including growing and shrinking its height from the top or bottom edge.
- Keep the sidebar visible when restoring a maximized window to its normal size.
- Temporarily hide the sidebar during the Windows 11 Snap Layouts preview and restore it after leaving the preview.

Windows 10 compatibility is not yet confirmed and remains a separate investigation.

Download **chatgpt-limit-panel-1.4.2-windows-x64.zip** under Assets. Git and a separate Node.js installation are not required. Update checks open the release page; installation remains manual. See the [upgrade guide](../UPGRADING.md).
