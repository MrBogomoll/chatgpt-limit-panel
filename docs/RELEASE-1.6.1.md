# ChatGPT Limit Panel 1.6.1

## Русский

- Упрощено обновление пакета: **остановить панель → заменить ZIP → нажать «Запустить»**. При обычном обновлении открывать Планировщик заданий больше не требуется.
- Новая версия автоматически проверяет свою остановленную задачу запуска и обновляет путь к программе, сохраняя выбор автозапуска и остальные настройки.
- Чужие, изменённые и ещё работающие задачи остаются без изменений. Поддерживается перенос задач прежних установок, даже если старый пакет уже удалён.
- Обновлена [инструкция по обновлению](../UPGRADING.md) на русском и английском.

Кнопка проверки новой версии по-прежнему открывает страницу выпуска; ZIP заменяется вручную. Совместимость с Windows 10 пока не подтверждена.

## English

- Simplified package updates: **stop the panel → replace the ZIP → click Start**. Routine updates no longer require opening Task Scheduler.
- The new version automatically validates its stopped launch task and updates the program path, preserving autostart choices and other preferences.
- Unrelated, modified or still-running tasks are left unchanged. Previous installations can be migrated even when the old package has already been removed.
- Updated the Russian and English [upgrade guide](../UPGRADING.md).

Check for a new version still opens the release page; ZIP replacement remains manual. Windows 10 compatibility remains unconfirmed.
