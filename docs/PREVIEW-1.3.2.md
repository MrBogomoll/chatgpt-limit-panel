# Quota Panel 1.3.2 — предварительная сборка

Ползунок прозрачности получил тонкую округлую дорожку и круглый бегунок.
Его цвета автоматически следуют выбранной теме Quota Panel.

При полностью прозрачном фоне вся область индикатора продолжает принимать ПКМ.
Проценты остаются непрозрачными. Исправлена гонка, из-за которой свежий снимок
панели задач мог ошибочно считаться просроченным после следующего измерения.

Исчезновение индикатора при открытии меню Start11 ещё исследуется. Сборка
содержит ограниченную локальную диагностику состояния окна и панели задач.
Это приватная предварительная сборка; публичный стабильный выпуск — 1.1.0.

## English

The transparency slider now uses a slim rounded track and a circular handle.
Its colours follow the selected Quota Panel theme.

The entire indicator remains available for right-clicks with a fully clear
background, while percentage text stays opaque. A race that could mark a fresh
taskbar snapshot as expired after the next measurement has been corrected.

The indicator disappearing with Start11's context menu is still being
investigated. This build includes bounded local window/taskbar diagnostics.
This is a private preview; the public stable release remains 1.1.0.
