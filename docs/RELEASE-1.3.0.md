# ChatGPT Limit Panel 1.3.0

- Добавлен отдельный индикатор лимитов на панели задач с выбором стороны размещения.
- Исправлено исчезновение индикатора при переключении из игр и открытии «Пуска» и меню Start11.
- Лимиты продолжают обновляться с закрытым окном ChatGPT при включённом индикаторе панели задач.
- Добавлен ползунок прозрачности фона; текст остаётся читаемым, меню доступно и при прозрачном фоне.
- Обновлены имена файлов и значков; сохранены темы, русский и английский интерфейсы и настройки панели.

Скачай готовый `chatgpt-limit-panel-1.3.0-windows-x64.zip` из Assets. Рядом находится файл SHA-256.
