Подключение к монитору…

При первом запуске настраивается автозапуск при входе в Windows. Панель ждёт открытия ChatGPT и появляется примерно через 3 секунды. Автозапуск можно отключить через ПКМ по панели. «Остановить» завершает текущий монитор; настройка автозапуска сохраняется. Windows x64, локальный исполнитель.
