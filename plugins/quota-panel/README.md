# Quota Panel

Язык интерфейса выбирается через **ПКМ → «Язык / Language» → «Русский / English»**. Выбор сохраняется после перезапуска. Переводятся подписи панели, меню, трей, карточка управления и сообщения; карточка подхватывает выбор при следующем обновлении состояния (обычно в течение 5 секунд). Язык самого ChatGPT не изменяется. Числа, даты и время сброса сохраняют прежний формат, а ультракомпактный вид остаётся без текста. По умолчанию используется русский.

**English:** Right-click the panel → **Language / Язык → English**. The choice is saved across restarts and applies to panel labels, context and tray menus, the control card and messages. The card picks it up on the next status refresh, normally within 5 seconds. ChatGPT's own language is not changed. Reset dates keep the DD.MM format and times use 24-hour HH:mm. The ultracompact view remains text-free. Russian is the default.

Тема панели и её меню выбирается через ПКМ → «Тема → Тёмная / Светлая / Авто». По умолчанию используется «Авто»: панель читает сохранённую настройку appearanceTheme клиента ChatGPT из раздела desktop в конфигурации Codex. Если в клиенте выбрана системная тема, используется Windows AppsUseLightTheme. Настройка проверяется примерно раз в секунду; ручной выбор панели имеет приоритет и сохраняется после перезапуска. Чтение не меняет тему, язык или другие настройки ChatGPT. Светлая палитра использует тёмный текст и более тёмные оранжевые/красные индикаторы для читаемости на светлом фоне.

Плагин для управления самостоятельным монитором лимитов в Windows x64. Карточка плагина содержит три кнопки: **«Запустить»**, **«Остановить»** и **«Обновить состояние»**. Монитор показывает общий остаток Codex/Work над окном ChatGPT. Дату и время сброса он получает с сервера; отдельную квоту Instant не запрашивает.

Закрытие карточки плагина и переход в другой разговор не останавливают монитор. Остановить его можно кнопкой в карточке или через значок монитора в трее. Когда ChatGPT не активен, панель скрывается, а монитор продолжает работать. После первой активации пользовательская задача запускает монитор при входе в Windows. Пока ChatGPT закрыт, панель скрыта и запросы квоты не выполняются; после открытия окно панели появляется примерно через 3 секунды.

ЛКМ переключает три вида по кругу: полный → компактный → ультракомпактный → полный. В меню ПКМ «Вид панели» можно выбрать любой вид напрямую. Ультракомпактный вид занимает 46×32 DIP: сверху полоска остатка 5-часового лимита, снизу недельного; цифр и времени нет. Обычная рамка остаётся всегда; цветной контур подчиняется общему меню «Индикатор». Позиция и размер рабочего окна применяются вместе; содержимое сохраняет пропорции и нижнюю привязку. Предпросмотр не меняет расположение рабочего содержимого.

ПКМ открывает настройки сбоку с зазором. Меню «Индикатор → Полоски / Контур / Полоски и контур / Без индикатора» едино для всех видов. В полном и компактном видах оно управляет обеими графиками. В ультракомпактном обе полоски видны всегда, а цветной контур добавляется только для «Контур» и «Полоски и контур». Отдельных переключателей контура компактного/ультракомпактного вида больше нет. «Лимит контура → 5 часов / Неделя» задаёт общий источник рамки, доступный и при выключенном контуре. Прежний выбор «Индикатор полного вида» переносится в общую настройку; источник и прочие сохранённые поля остаются. Меню закрывается при клике снаружи, включая пустое место боковой панели; нажатия внутри его подменю позволяют продолжать выбор. Пункт «Автозапуск с ChatGPT» включает или отключает запуск после входа в Windows. «Остановить» завершает текущий монитор без немедленного повторного запуска; для постоянного отключения автоматического старта сними соответствующую галочку. В меню также доступны обновление, пауза и остановка.

При положительном остатке полоски и контур показывают оставшийся процент. При остатке <=30% они приглушённо-оранжевые, <=10% — приглушённо-красные. Известный0% обозначается полностью красной полоской и целиком красным включённым контуром выбранного лимита; само число остаётся0%. Это предупреждение об исчерпании, а не100% доступной квоты. Неизвестные данные не рисуют заполнение, выключенные индикаторы остаются выключенными; устаревшие известные данные затемнены и сохраняют явную подпись «устар.».

При установке у другого пользователя пути и SID берутся на его компьютере. Один раз нажми «Запустить» в карточке: создаётся или обновляется только его задача Quota Panel, без администратора и пароля. Один импорт ZIP не выполняет Windows-настройку. После первичной активации повторное ручное включение после входа в Windows не требуется.

## Локальная установка

Готовый пакет `quota-panel` для Windows x64 устанавливается через локальный marketplace Codex. Папка с исходниками не заменяет собранный пакет: дополнительно нужны нативный монитор, Node и лицензия Node. Создание ZIP само по себе не устанавливает плагин.

В исходном проекте команда `node overlay/install-plugin.mjs "<папка готового пакета>"` создаёт отдельный локальный marketplace `quota-panel-local`, сохраняет резервную копию настроек и устанавливает плагин штатной командой Codex. Установщик проверяет, что Codex сообщает правильную версию и состояние «установлен и включён». Другие плагины сохраняются.

После установки открой **«Quota Panel»** в меню плагинов. Для проверки можно выполнить `codex plugin list --marketplace quota-panel-local --json`. Если открытый список ещё не обновился, закрой и открой его; при необходимости перезапусти клиент. В новом локальном чате выбери плагин и попроси открыть управление панелью лимитов. Доступность глобального пункта зависит от клиента и локального исполнителя.

Этот пакет не публикуется автоматически. Передача готового ZIP другому человеку не публикует его в общем каталоге плагинов.

## Аккаунт и данные

Нужен установленный Codex с выполненным входом в нужный аккаунт. Монитор запускает штатный Codex App Server и читает `account/rateLimits/read` с текущим локальным входом. API-ключ не требуется. Вход локального Codex должен соответствовать аккаунту, лимиты которого нужно показать.

Каждый получатель использует собственный локальный аккаунт. Архив не содержит авторизацию, токены, переписку или настройки аккаунта автора. Плагин не читает файлы токенов напрямую и не меняет оригинальный клиент ChatGPT.

## Ограничения текущей версии

- Поддерживается Windows x64 и установленный настольный клиент, который распознаёт существующий монитор. Браузерный ChatGPT и macOS не поддерживаются этой сборкой.
- Интерфейс управления требует локальный исполнитель. После запуска монитор самостоятельно следит за окном; открытая карточка плагина ему не нужна.
- Изменение расположения элементов в будущей версии ChatGPT может потребовать обновления привязки панели.
- Плагин управляет одним экземпляром монитора в текущем сеансе Windows. Если монитор был запущен ярлыком, карточка показывает его состояние и может остановить его.

Версия: `0.2.0-beta.3`. Поддерживаемые команды: `show_quota_overlay`, `start_quota_overlay`, `stop_quota_overlay`, `get_quota_overlay_status`.
