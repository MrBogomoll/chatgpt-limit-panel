# Quota Panel

<img src="plugins/quota-panel/assets/quota.svg" width="80" height="80" alt="Quota Panel">

Приватная бета-версия панели остатка лимитов Codex / Work для Windows x64. Панель располагается поверх левой навигационной полосы настольного ChatGPT, над аватаркой. Исходный клиент не изменяется. Плагин в меню ChatGPT открывает карточку с кнопками запуска, остановки и проверки состояния самостоятельного монитора.

**Версия: 0.2.0-beta.3.** Репозиторий и сборка пока предназначены для частного тестирования. Публикация в общем каталоге плагинов не выполнялась.

## Возможности

- Общий 5-часовой и недельный счётчик Codex / Work во всех режимах окна ChatGPT, включая Instant. Отдельная квота Instant не запрашивается.
- Проценты остатка и серверное время сброса через штатный Codex App Server, обновление раз в 30 секунд.
- Полный, компактный и ультракомпактный виды; ЛКМ переключает их по кругу.
- Полоски, контур, оба индикатора или отключение графики. В ультракомпактном виде две полоски остаются всегда.
- Единый выбор 5-часового или недельного лимита для контура. При известном нуле включённый индикатор становится полностью красным.
- Приглушённое оранжевое предупреждение при остатке ≤30%, красное — ≤10%. Устаревшие данные обозначаются «устар.», неизвестные — прочерком.
- Тёмная, светлая и автоматическая темы. Авто учитывает сохранённую тему приложения и системную тему Windows.
- Сохранение настроек и автозапуск: после первой активации монитор запускается при входе пользователя в Windows и ждёт открытия ChatGPT; панель появляется примерно через 3 секунды.

## Требования и запуск

Нужны Windows x64, настольный ChatGPT с локальным исполнителем и установленный Codex с выполненным входом в нужный аккаунт. API-ключ не требуется. Локальный аккаунт Codex должен соответствовать аккаунту, лимиты которого нужно видеть.

Готовый ZIP находится в разделе [Releases](../../releases) приватного репозитория вместе с SHA-256. В него входят монитор, Node.js и лицензия Node; отдельная установка Node для работы готового пакета не требуется. Исходный ZIP репозитория от GitHub отличается от собранного ZIP плагина.

Штатная локальная установка из исходников после распаковки готовой сборки:

~~~powershell
node overlay/install-plugin.mjs "<папка распакованного готового пакета>"
~~~

Установщик использует команду Codex из PATH, создаёт отдельный локальный marketplace и сохраняет резервную копию конфигурации перед установкой. Сам ZIP содержит совместимый манифест для импорта в поддерживающий его клиент. Не копируй авторский plugin.json вручную в корень собранного пакета: текущий настольный парсер использует .codex-plugin/plugin.json.

После установки открой **Quota Panel** в меню плагинов и нажми **«Запустить»** в карточке управления. Первый запуск создаёт собственную пользовательскую задачу Windows без администратора и пароля. Сам импорт ZIP не выполняет настройку Windows. Каждый получатель активирует автозапуск один раз на своём компьютере; затем повторное ручное включение после входа в Windows не требуется.

В меню ПКМ есть **«Автозапуск с ChatGPT»**. Его отключение не закрывает уже работающую панель. Команда **«Остановить панель»** завершает текущий монитор; для постоянного отключения автоматического запуска также сними галочку автозапуска.

## Сборка и проверки

Для разработки нужны Node.js 24 x64 и штатный компилятор .NET Framework 4.x в Windows. Браузерная проверка карточки использует Playwright 1.62.1 и установленный Microsoft Edge.

~~~powershell
npm install
npm test
npm run build:overlay
npm run package:plugin
~~~

Сборка создаёт EXE в dist/overlay, упаковка — ZIP и контрольную сумму в dist/releases. В пакет включается исполняемый Node, которым запущена упаковка; для этой беты использован Node.js 24.22.1 x64. Файл third-party/NODE-LICENSE.txt соответствует этой версии: при смене Node обнови и его лицензионные уведомления. Повторная упаковка сохраняет прежние результаты и отказывается затирать существующий архив.

Без npm проверки можно запустить напрямую после установки Playwright:

~~~powershell
node --test tests/plugin-reader.test.mjs tests/plugin-quota.test.mjs tests/quota-panel-*.test.mjs tests/overlay-*.test.mjs
node overlay/build.mjs
node overlay/build.mjs --test-layout
.\dist\overlay\layout-test.exe
~~~

Тесты используют временные каталоги, подставной сервер квот и собственные окна WPF вне экрана. Живую проверку установленной сборки запускают отдельно: node overlay/smoke-package.mjs "<папка готового пакета>". Она запускает и останавливает собственный монитор, поэтому не входит в обычный набор тестов.

## Структура

- plugins/quota-panel — манифесты, MCP-сервер, карточка управления и иконка.
- overlay — окно WPF, монитор, задача Windows, темы, привязка к окну и инструменты сборки/упаковки/проверки.
- plugins/quota-chips/server — только общий считыватель и нормализация квоты; историческое имя каталога сохранено для совместимости импортов.
- tests — проверки действующего плагина и монитора. Старый эксперимент с модифицированной копией клиента в этот репозиторий не включён.
- third-party — уведомления о лицензиях компонентов готовой сборки.

## Ограничения беты и данные

Панель является самостоятельным окном Windows, привязанным к окну ChatGPT. Она скрывается, когда ChatGPT не активен. Это не произвольное изменение интерфейса клиента через API плагинов. macOS, браузерная версия и все варианты будущего интерфейса этой сборкой не поддерживаются.

Автозапуск сохраняется в пользовательской задаче Windows. Миграция задачи на путь следующей версии плагина и автоматическая очистка при удалении ещё требуют отдельной проверки перед публичным релизом. Реальная перезагрузка Windows не выполнялась в последней проверке; определение задачи, включение/отключение триггера и запуск установленной сборки проверены отдельно.

Рабочие настройки и собственный рендер панели хранятся в %LOCALAPPDATA%\ChatGPTQuotaOverlay. Рендер содержит только панель, без снимка рабочего стола. Авторизация, токены, переписки, локальные настройки аккаунта и рабочие журналы в репозиторий и готовый пакет не включены. Каждый получатель использует свой локальный вход Codex.

Исходники пока не предоставлены под публичной лицензией. Сторонние компоненты распространяются на условиях, перечисленных в их уведомлениях.
