# ChatGPT Limit Panel

[English](README.en.md)


<img src="plugins/chatgpt-limit-panel/assets/chatgpt-limit-panel.png" width="88" height="88" alt="ChatGPT Limit Panel">

Панель лимитов **Codex / Work** для настольного ChatGPT в Windows. Показывает остаток 5-часового и недельного лимитов, время их сброса, доступные сбросы с датой истечения и остаток кредитов Codex. Три размера панели, светлая и тёмная темы, индикаторы на панели задач и в трее.

**[Скачать для Windows x64](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/latest)** · [Обновление](UPGRADING.md) · [Полное удаление](UNINSTALL.md) · [Все релизы](https://github.com/MrBogomoll/chatgpt-limit-panel/releases)

На странице выпуска скачай готовый ZIP программы из **Assets**. Архивы **Source code** содержат исходники и не предназначены для установки как плагин.

Уже установлена панель? Нажми **ПКМ по панели → Проверить новую версию → Обновить**. Если кнопки **«Обновить»** нет, см. [ручное обновление](UPGRADING.md).

## Возможности

- **Лимиты Codex / Work:** остаток за 5 часов и за неделю, даты и время сброса. Лимиты обновляются примерно раз в 30 секунд. В Instant отображаются те же счётчики. Если пятичасового ограничения нет, например на Pro, панель автоматически скрывает его и переносит контур на недельный лимит. В **Содержимое панели → Лимиты** можно оставить оба блока (с ∞) или показывать только недельный.
- **Доступные сбросы:** количество и ближайшее истечение на панели; список всех сбросов с датами и временем в подменю. За 10 дней до истечения блок становится оранжевым, за 3 дня — красным. Просмотр не расходует сбросы.
- **Кредиты Codex:** отдельный остаток между сбросами и лимитами. Сбросы и кредиты включаются независимо. Денежный баланс API текущий источник не предоставляет.
- **Три размера:** полный, компактный и ультракомпактный; ЛКМ переключает виды, ПКМ открывает настройки. При нехватке места панель автоматически уменьшается.
- **Полоски и контур:** можно выбрать сочетание индикаторов и лимит для контура. При остатке ≤30% используется оранжевый, при ≤10% — красный. В ультракомпактном виде полоски видимых лимитов остаются включёнными, а устаревшие данные бледнеют.
- **Расположение:** закрепление на боковой полосе или свободное перетаскивание внутри ChatGPT. Положение сохраняется и сбрасывается через меню.
- **Панель задач и трей:** перетаскиваемый индикатор с процентами лимитов или кредитами Codex и отдельно включаемая живая иконка в трее.
- **Оформление:** тёмная, светлая и автоматическая темы, русский и английский языки, независимая непрозрачность фона панели и индикатора на панели задач. Настройки сохраняются.

## Установка

Нужны Windows x64, настольный клиент ChatGPT с поддержкой локальных плагинов и установленный Codex со входом в нужный аккаунт. Отдельные API-ключ, Git и Node.js не требуются.

Скачай готовый ZIP из раздела **Assets** и выбери один способ:

- **Через интерфейс:** открой **Плагины → Добавить → Загрузить архив плагина** и выбери ZIP.
- **Через локальный установщик, чтобы обновляться одной кнопкой:** распакуй ZIP, открой PowerShell в распакованной папке и выполни команду ниже. Команда `codex --version` должна работать в том же PowerShell.

  ```powershell
  .\runtime\node.exe .\overlay\install-plugin.mjs .
  ```

После установки открой [карточку управления](#как-открыть-карточку-управления) и нажми **«Запустить»**.

При первом запуске создаётся пользовательская задача запуска Windows; автозапуск можно отключить в настройках панели. Индикатор панели задач включается через **Расположение → Панель задач → Показывать индикатор**. В этом же подменю **«Что показывать»** переключает проценты и кредиты. Живая иконка включается через **Расположение → Живая иконка в трее**.

При включённом индикаторе панели задач **или** живой иконке монитор может обновлять лимиты без открытого окна ChatGPT. Закрытие карточки управления не останавливает монитор; для остановки выбери **«Остановить панель»**.

## Как открыть карточку управления

Карточка — это ответ плагина в чате с кнопками **«Запустить»**, **«Остановить»** и **«Обновить состояние»**.

1. Открой новый чат в настольном приложении, где установлен плагин.
2. В поле сообщения введи **@**, начни писать **ChatGPT Limit Panel** и выбери его в разделе **«Плагины»**.
3. Отправь: **«Открой управление панелью лимитов Codex/Work»**. В ответе появится карточка управления.

Если плагина нет в списке, проверь его установку и включение в **«Плагины»**. После обновления открой новый чат, чтобы он получил новые инструменты. Выбор через @ описан в [документации OpenAI](https://learn.chatgpt.com/docs/build-plugins).

## Обновление и удаление

Бирюзовая точка означает, что вышла новая стабильная версия. Её можно скрыть через **Настройки → Показывать точку обновления**. Проверка и установка останутся доступны.

**Обновить:** открой меню самой панели и выбери **«Проверить новую версию» → «Обновить»**. Панель проверит архив и перезапустится, ChatGPT можно оставить открытым. Если доступно только **«Открыть релиз»**, воспользуйся [инструкцией для ZIP](UPGRADING.md).

**Удалить:** [карточка управления](#как-открыть-карточку-управления) → **Настройки плагина → Удалить плагин…**. В отдельном окне можно выбрать, сохранять ли настройки и журнал. См. [полное удаление](UNINSTALL.md) и [историю изменений](CHANGELOG.md).

## Совместимость и данные

Панель проверена на Windows 11, в том числе с установленным Start11. Совместимость с Windows 10 пока не подтверждена. Если загрузка ZIP недоступна или возникла ошибка, укажи версию Windows, клиента и описание в [Issues](https://github.com/MrBogomoll/chatgpt-limit-panel/issues).

Панель запрашивает лимиты текущего аккаунта через локальный Codex App Server. Настройки и журнал сбоев хранятся в `%LOCALAPPDATA%\ChatGPTLimitPanel` (в старых установках — `ChatGPTQuotaOverlay`). Журнал сохраняет этап и длительность последних неудачных попыток, без токенов и ответов сервера. За версиями и архивами панель обращается к GitHub. Контрольная сумма SHA-256 лежит рядом с ZIP в **Assets** каждого выпуска. Проект независимый и не является официальным продуктом OpenAI.

Сообщение об уязвимостях: [политика безопасности](SECURITY.md).
