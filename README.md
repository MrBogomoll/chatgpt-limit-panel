# Quota Panel

Локальная тестовая сборка **1.2.1-beta.3**: дочернее прикрепление индикатора к панели задач по образцу NetWorx. Порядок и видимость теперь следуют родительской панели; реальное поведение в играх и меню проходит проверку. Готовый архив 1.2.0 сохранён.

[English documentation](README.en.md)

<img src="plugins/quota-panel/assets/quota.svg" width="80" height="80" alt="Quota Panel">

Панель остатка лимитов Codex / Work для Windows x64. Обычная панель располагается над аватаркой в левой навигационной полосе настольного ChatGPT. Дополнительный индикатор показывает два процента на панели задач Windows. Оба используют один общий счётчик аккаунта.

**Сборка к выпуску: 1.2.0. Последний публичный стабильный выпуск: 1.1.0.** Архив 1.2.0 подготавливается отдельно от публикации. Исходники остаются приватными; Quota Panel не опубликована в общем каталоге плагинов OpenAI.

## Новое в 1.2.0

- Необязательный индикатор на основной панели задач: сверху процент остатка 5-часового лимита, снизу недельного. Предпочтительное размещение выбирается слева или справа среди проверенных свободных промежутков.
- Получение квоты продолжается при закрытом окне ChatGPT, если индикатор панели задач включён. Управление доступно через значок Quota Panel в трее.
- Общий ползунок прозрачности фона 0–100% в меню индикатора. Текст и графика остаются непрозрачными; при полностью прозрачном фоне сохраняется область для ПКМ.
- Уточнена обработка активного меню Start11: уже показанный индикатор удерживает проверенное место, пока меню блокирует получение расположения кнопок.
- Устранена ошибка, из-за которой свежий снимок расположения элементов мог ошибочно считаться просроченным.

[Описание выпуска на русском и английском](docs/RELEASE-1.2.0.md).

## Основные возможности

- Общий 5-часовой и недельный остаток Codex / Work во всех режимах поддерживаемого окна ChatGPT, включая Instant. Отдельная квота Instant не запрашивается.
- Проценты и серверные даты сброса через штатный Codex App Server; обновление примерно раз в 30 секунд.
- Полный, компактный и ультракомпактный виды. ЛКМ переключает их по кругу, меню ПКМ позволяет выбрать вид напрямую.
- Полоски, контур, оба индикатора или отключение графики. В ультракомпактном виде две полоски видны всегда; цветной контур включается общей настройкой.
- Единый выбор 5-часового или недельного лимита для контура всех видов. Известный ноль отображается полностью красным включённым индикатором; неизвестные значения обозначаются прочерком и не заполняют графику.
- Приглушённое оранжевое предупреждение при остатке ≤30%, красное — ≤10%. Устаревшие известные значения затемнены и помечены «устар.».
- Тёмная, светлая и автоматическая темы; русский и английский интерфейсы. Выбор сохраняется и не меняет язык или тему самого ChatGPT.
- Пользовательский автозапуск после первой активации. Обычная панель появляется примерно через 3 секунды после открытия ChatGPT.

## Управление

В меню плагинов открой **Quota Panel** и карточку управления. В ней есть запуск, остановка, обновление состояния и ручная проверка новой версии. Закрытие карточки не останавливает монитор.

ПКМ по обычной панели открывает настройки вида, темы, языка, графики, источника контура и автозапуска. Верхняя строка — 5 часов, нижняя — неделя. В компактном виде остаются процент и время 5-часового сброса, затем процент и дата недельного сброса. Даты используют ДД.ММ, время — ЧЧ:ММ в локальном часовом поясе.

Для панели задач: **ПКМ → «Панель задач» → «Показывать проценты»**, затем **«Слева»** или **«Справа»**. По умолчанию индикатор выключен. ПКМ по нему → **«Прозрачность фона»** меняет фон обоих отображений; по умолчанию — 50%. Те же настройки доступны через трей, когда обычная панель скрыта.

**«Проверить новую версию»** проверяет стабильные выпуски GitHub; **«Приостановить обновление лимитов»** останавливает получение квоты. При наличии новой версии **«Открыть релиз»** ведёт на страницу скачивания. Установка обновления остаётся ручной; Git и вход в GitHub для проверки не требуются.

## Требования и установка

Нужны Windows x64, настольный ChatGPT с локальным исполнителем и установленный Codex с выполненным входом в нужный аккаунт. Локальный аккаунт Codex должен соответствовать аккаунту, лимиты которого нужно видеть. API-ключ не требуется.

Опубликованные готовые архивы и SHA-256 размещаются в [публичных Releases](https://github.com/MrBogomoll/quota-panel-chatgpt/releases). Для 1.2.0 используй отдельно подготовленный архив сборки, пока выпуск не опубликован. В готовый ZIP входят монитор, Node.js и его лицензия; отдельная установка Node для работы пакета не требуется. Автоматический архив GitHub **Source code** отличается от собранного ZIP плагина.

Используй штатный импорт архива в клиенте, поддерживающем этот формат локальных плагинов. Для установки из исходного checkout доступна команда:

```powershell
node overlay/install-plugin.mjs "<папка распакованного готового пакета>"
```

Она регистрирует отдельный локальный marketplace через Codex CLI из PATH и сохраняет резервную копию конфигурации. В собранном пакете используется `.codex-plugin/plugin.json`; авторский корневой `plugin.json` не нужно переносить вручную.

После установки открой **Quota Panel** и нажми **«Запустить»** один раз. Это настраивает собственную пользовательскую задачу Windows без администратора и пароля. Сам импорт ZIP не выполняет настройку Windows. Монитор запускается при входе пользователя; при выключенном индикаторе панели задач он ждёт окно ChatGPT, а при включённом продолжает получать квоту без него.

**«Автозапуск с ChatGPT»** управляет будущим автозапуском. **«Остановить панель»** завершает текущий монитор. Для постоянного отключения после следующего входа в Windows также отключи автозапуск.

## Ограничения и данные

Известная проблема 1.2.0: при вызове «Пуска» поверх игры в режиме окна без рамки
индикатор панели задач может исчезать. Случай замечен в Honkai: Star Rail и Hollow
Knight: Silksong; исправление выделено в отдельный последующий патч.

Панели — самостоятельные окна Windows. Они не изменяют файлы ChatGPT и не внедряют код в Проводник. Обычная панель следует видимому окну ChatGPT, его масштабу и порядку наложения; скрывается вместе со свёрнутым, закрытым или скрытым окном.

Индикатор панели задач использует измеренное свободное место на **основной** панели задач и не резервирует системный слот. Он скрывается при нехватке места, полноэкранном режиме или неопределённой геометрии. Поддержка панели задач снизу, сверху, слева и справа экспериментальная. Совместимость со всеми сторонними модификаторами, виджетами, конфигурациями мониторов и масштабирования не гарантируется. Windows 10 не проверялась на отдельном компьютере; [сравнение Windows 10/11 и подходов](docs/research/2026-10-27-windows-taskbar-research.md).

Поддерживаются текущий распознаваемый настольный клиент и локальный исполнитель Windows x64. macOS и браузерный ChatGPT этой сборкой не поддерживаются. Изменения интерфейса будущего клиента могут потребовать обновления привязки.

Настройки, состояние и ограниченная локальная диагностика хранятся в `%LOCALAPPDATA%\ChatGPTQuotaOverlay`. Рендер панели содержит только её содержимое; снимки рабочего стола не создаются. Авторизация, токены, переписки и настройки аккаунта автора в репозиторий и готовый пакет не включены. Каждый получатель использует свой вход Codex. Автоматическая очистка задачи Windows при удалении плагина ещё требует отдельной проверки.

## Разработка и версии

Основной репозиторий с кодом — приватный `quota-panel-code`. Публичный `quota-panel-chatgpt` хранит пользовательские материалы и готовые выпуски. У одной готовой версии один номер в исходниках, манифесте, архиве и публичном релизе.

Прежние обозначения `1.2.x` и `1.3.x` относились к закрытым промежуточным сборкам. Их изменения объединены в готовящуюся 1.2.0. Исторические заметки сохранены для истории разработки. Для будущих промежуточных сборок используется схема `1.3.0-beta.1`, `beta.2`, затем готовый выпуск `1.3.0`; это правило нумерации не включает автоматически отдельный канал доставки бета-версий. [Правила выпусков](docs/RELEASE_NOTES.md).

Для сборки нужны Node.js 24 x64 и штатный компилятор .NET Framework 4.x в Windows. Браузерная проверка карточки использует Playwright 1.62.1 и установленный Microsoft Edge.

```powershell
npm install
npm test
npm run build:overlay
npm run package:plugin
```

Сборка создаёт EXE в `dist/overlay`, упаковка — ZIP и контрольную сумму в `dist/releases`. В пакет входит Node, которым запущена упаковка; при смене его версии обнови `third-party/NODE-LICENSE.txt`. Повторная упаковка сохраняет прежние результаты и отказывается затирать существующий архив.

Проверки используют временные каталоги, подставной источник квот и собственные окна вне экрана. Отдельный `overlay/smoke-package.mjs` запускает и останавливает монитор установленной сборки и не входит в обычный набор проверок.

Исходники пока не предоставлены под публичной лицензией. Сторонние компоненты распространяются на условиях их уведомлений. Требования общей подачи плагина: [инструкция на русском](docs/PUBLISHING-RU.md).
