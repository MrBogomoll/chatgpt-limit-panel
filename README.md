# ChatGPT Limit Panel

[English](README.en.md)

<img src="plugins/chatgpt-limit-panel/assets/chatgpt-limit-panel.png" width="88" height="88" alt="ChatGPT Limit Panel">

Панель для Windows показывает оставшиеся **5-часовой и недельный лимиты Codex / Work** и время их сброса. Она располагается поверх окна настольного ChatGPT; по желанию можно включить индикатор на панели задач и живую иконку в трее. В режиме Instant отображается тот же счётчик Codex / Work.

**[Скачать для Windows x64](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/latest)** · [Обновление](UPGRADING.md) · [Полное удаление](UNINSTALL.md) · [Все релизы](https://github.com/MrBogomoll/chatgpt-limit-panel/releases)

На странице выпуска скачай готовый ZIP программы из **Assets**. Архивы **Source code** содержат исходники и не предназначены для установки как плагин.

## Возможности

- Остаток лимитов и время сброса из Codex; данные обновляются примерно раз в 30 секунд. Устаревшие и неизвестные значения помечаются отдельно.
- Полный, компактный и ультракомпактный виды; ЛКМ переключает их, ПКМ открывает настройки.
- Закрепление на боковой полосе или свободное перетаскивание внутри окна ChatGPT. Положение сохраняется; пункт «Расположение по умолчанию» возвращает панель к боковой полосе.
- Независимая непрозрачность фона панели и индикатора на панели задач. Установи **100% непрозрачности фона** панели, чтобы текст переписки не просвечивал.
- Полоски и контур показывают остаток; для контура можно выбрать 5-часовой или недельный лимит. При остатке ≤30% используется приглушённый оранжевый, при ≤10% — красный. В ультракомпактном виде две полоски видны всегда.
- Индикатор на панели задач с процентами и выбираемым расположением; живая иконка в трее с теми же двумя лимитами включается отдельно.
- Тёмная, светлая и автоматическая темы; русский и английский языки. Настройки сохраняются.

## Установка

Нужны Windows x64, настольный клиент ChatGPT с поддержкой локальных плагинов и установленный Codex со входом в нужный аккаунт. Отдельные API-ключ, Git и Node.js не требуются.

1. Скачай готовый ZIP по ссылке выше.
2. Открой **Плагины → Добавить → Загрузить архив плагина** и выбери ZIP.
3. Открой **ChatGPT Limit Panel** и его карточку управления.
4. Нажми **«Запустить»**.

При первом запуске создаётся пользовательская задача автозапуска Windows; её можно отключить в меню панели. Чтобы включить индикатор панели задач, нажми **ПКМ по панели → Панель задач → Показывать проценты**. Живая иконка включается через **ПКМ по значку в трее → Живая иконка в трее**.

При включённом индикаторе панели задач **или** живой иконке монитор может обновлять лимиты без открытого окна ChatGPT. Закрытие карточки управления не останавливает монитор; для остановки выбери **«Остановить панель»**.

## Обновление и удаление

**«Проверить новую версию»** проверяет стабильный выпуск и предлагает открыть его страницу. ZIP устанавливается вручную. Инструкции: [обновление](UPGRADING.md) · [полное удаление](UNINSTALL.md). История изменений находится в [CHANGELOG](CHANGELOG.md) и [релизах](https://github.com/MrBogomoll/chatgpt-limit-panel/releases).

## Совместимость и данные

Панель проверена на Windows 11, включая Start11 и расположение рядом с NetWorx. Совместимость с Windows 10 пока не подтверждена. Если загрузка ZIP недоступна или возникла ошибка, укажи версию Windows, клиента и описание в [Issues](https://github.com/MrBogomoll/chatgpt-limit-panel/issues).

Программа использует текущий локальный вход Codex. Авторизация и настройки пользователя не входят в архив. Проект независимый и не является официальным продуктом OpenAI. [Контрольная сумма ZIP 1.6.1](https://github.com/MrBogomoll/chatgpt-limit-panel/releases/download/v1.6.1/chatgpt-limit-panel-1.6.1-windows-x64.zip.sha256).
